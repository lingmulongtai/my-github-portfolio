# Site preview provenance

These are static examples, not live embeds. Desktop images were captured from the listed public destinations on 2026-10-28 JST, then resized without cropping and optimized as WebP. The AeroGrid image shows its explicitly labelled Global Demo. The Windows and Mac images show their public GitHub introduction pages.

The Tsuyu Labo image is the public project's [documented development screenshot](https://github.com/lingmulongtai/tsuyulabo/blob/main/docs/media/screens/home-light.webp), Git blob `e77aa4157d2c45eae9e2ed9872203b6f5fae74f5`. The source README describes it as a local play screenshot and notes that some creature artwork is from before replacement. It is presented as a development preview; the public app was still loading during capture.

Previews are displayed only while their saved destination matches the current site URL. Screenshots are point-in-time examples and may become outdated; replace them after significant site changes. Repositories without a verified preview retain their existing concept illustration.
